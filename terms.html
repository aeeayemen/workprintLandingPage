2. Description of Service

Workprint is an Atlassian Cloud application designed to provide engineering managers, agile leads, and developers with cross-platform capacity intelligence:

  • Cross-Product Telemetry: Aggregates live task assignments, remaining estimates, and time spent from Jira Cloud; active documentation pages from Confluence Cloud; and open pull request reviews and turnaround lag from Bitbucket Cloud.
  • Interactive Admin Dashboard: Accessible via Jira and Confluence global page modules to visualize squad bandwidth, identify review bottlenecks, and reassign sprint tasks.
  • Atlassian Rovo AI Integration: Provides the workprint-rovo-agent and analyze-workprint action for natural language workload queries and capacity balance advisories directly in Atlassian Rovo chat.
