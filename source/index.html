Atlassian Forge Platform Security

Zero Outside-Cloud Storage Architecture

Unlike legacy Connect plugins that transmit your proprietary telemetry to third-party servers, Workprint runs 100% inside Atlassian Forge's secure cloud sandbox.

Atlassian Tenant Isolation

Forge functions execute inside Node.js 22 containers isolated within your Atlassian site. Cross-tenant data leakage is architecturally prohibited.

Personal Data Declaration Guarantee

Workprint does NOT copy, store, or cache user identifiers or personal data beyond 24 hours outside Atlassian Cloud. All queries execute ephemerally in volatile memory.

Strict Egress Controls

External network communication is strictly confined to https://api.bitbucket.org as registered in the app manifest. Zero third-party trackers or ads.

App Distribution

Deploy Workprint to Your Atlassian Cloud Site

Deploy in minutes with Atlassian Forge CLI or install via Atlassian Marketplace.

STEP 01
Install App

Install Workprint onto your Jira Cloud and Confluence Cloud instance via the Atlassian Forge CLI:

forge install --site workprint.atlassian.net --product jira
STEP 02
Connect Bitbucket

Add your workspace Repository Access Token with read:pullrequest scope to enable review lag calculations.

Enable Rovo AI Agent
