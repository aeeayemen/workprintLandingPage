Install Workprint on Your Site

Workprint installs directly into your Atlassian Cloud workspace in seconds with zero outside-cloud database configuration required.

1. Install via Forge CLI:
forge install --site workprint.atlassian.net --product jira
2. Or Install via Atlassian Marketplace:

Search for Workprint in Jira / Confluence Marketplace under Apps.
